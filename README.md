# Gromo

A personal workout tracker. Log my weekly lifts, see whether I'm trending **up**, and get
a nudge to add weight when I complete a target (double progression over a rep range).

Offline-first React PWA — data lives in the browser (`localStorage`), backed up via JSON
export/import. No server, no accounts. Hosted on GitHub Pages, installable to the phone.

See [PLAN.md](./PLAN.md) for the full design.

## Develop

```
npm install
npm run dev
```

## Deploy (GitHub Pages)

```
npm run deploy
```
